# FOLI-05 · Continue reading from the home screen — Core

**As a** reader, **I want to** find my current book and a clear way to continue, **so that** I can start with few interactions.

**Acceptance criteria**

- The home screen shows the current book's cover or placeholder, title, and progress percentage, and highlights “Continue reading.”
- If two books are active, I can choose which one to continue; if none are active, I am offered a way to add or activate one.
- When available, the screen quietly shows today's goal, the streak, and a pending action without becoming a statistics dashboard.
- I can reach the start of a session without relying on a network connection.

**Depends on:** FOLI-03, FOLI-06, FOLI-09; the streak and action can appear when FOLI-11 and FOLI-17 are implemented. **PRD:** §§4, 18.
