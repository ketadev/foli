# FOLI-18 · Track and evaluate an action — MVP expansion

**As a** reader, **I want to** track an action and evaluate whether it worked for me, **so that** I can complete the cycle from reading to applying an idea.

**Acceptance criteria**

- I can move an action among Pending, In Progress, Applied, and Discarded through defined transitions.
- If the action has a duration, I can record whether I did it on each day of that period and review those entries.
- When finished, I can evaluate it as Yes, Partly, or No; discarding it does not require an evaluation.
- The action and its evaluation persist offline. Tracking an action never blocks new reading sessions.

**Depends on:** FOLI-17. **PRD:** §17.
