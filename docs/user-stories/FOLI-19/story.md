# FOLI-19 · See a pending action on the home screen — MVP expansion

**As a** reader, **I want to** see a relevant pending action, **so that** I can remember it without opening a long list.

**Acceptance criteria**

- If a Pending or In Progress action exists, the home screen shows one with a way to open its tracking view.
- If none exists, that space does not distract from “Continue reading.”
- The action never replaces the primary way to start reading.

**Depends on:** FOLI-05, FOLI-18. **PRD:** §18.
