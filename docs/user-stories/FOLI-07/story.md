# FOLI-07 · Read on a simple session screen — Core

**As a** reader, **I want to** read without distractions, **so that** I can focus on the book.

**Acceptance criteria**

- The screen shows the book, page goal, and session progress.
- I can end the session from this screen and record the page I reached.
- Ideas, actions, and suggestions do not interrupt reading or prevent me from finishing.
- The screen works offline.

**Depends on:** FOLI-06. **PRD:** §§4, 9.
