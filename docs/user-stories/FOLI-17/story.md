# FOLI-17 · Turn an idea into my own action — MVP expansion

**As a** reader with the Read and apply intention, **I want to** turn an idea into a concrete action, **so that** I can try it outside the book.

**Acceptance criteria**

- I can write and save an action based on an idea from the book; AI is not required.
- Each idea can have at most one action, and an attempt to create another shows the existing link.
- The action starts as Pending and can have a duration when relevant.
- Skipping or leaving this step does not change the idea or the session already saved.

**Depends on:** FOLI-15, FOLI-04. **PRD:** §§15, 16.
