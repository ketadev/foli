# FOLI-09 · View book progress — Core

**As a** reader, **I want to** see each book's progress percentage and current page, **so that** I know how much remains.

**Acceptance criteria**

- A book shows a percentage calculated from its current page and total pages, between 0% and 100%.
- After I complete a session, the visible progress updates immediately and matches the saved page.
- I do not need to open detailed statistics to see it.

**Depends on:** FOLI-08. **PRD:** §11.
